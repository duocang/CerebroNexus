# 本机 Linked View 快照库设计

## 目标

让用户在同一浏览器和同一细胞群中，为当前 linked-view 工作区创建可命名、可恢复、可删除并可下载的本机快照；快照不上传到服务端。

## 范围

- 在现有 `Import / export view…` 面板中增加 `Saved views` 区域。
- 每个快照保存服务端 canonical JSON、用户名称及本机保存时间。
- 快照按配置内的 `dataset.cell_fingerprint` 隔离；当前数据集之外的快照完全不显示。
- 用户可保存、恢复、重命名、删除、下载某个快照。
- 已有 Open JSON、Copy JSON、Download JSON 的验证与失败语义保持不变。

## 不在范围内

- 不上传、同步或生成公共链接。
- 不跨数据集映射 barcode，也不恢复部分匹配的配置。
- 不新增账户、权限或服务器端持久化。

## 数据模型

浏览器 `localStorage` 使用一个版本化库记录。每条记录包含稳定 id、名称、保存时间和 canonical JSON；数据集指纹从该 JSON 读取，不另造第二个真相来源。库带固定的条数和总字节上限；保存会先请求并接收现有服务器边界生成的 canonical JSON，再写入本机。

快照名称只属于本机库元数据，不修改可移植 JSON v1 格式。因此旧文件、复制和下载的互操作性不受影响，未来服务器共享也可以直接复用同一 canonical JSON。

## 交互

用户有活动 selection 时可选择 `Save current view`，输入非空名称后保存。快照列表显示名称和本机保存时间；点击名称恢复，溢出菜单提供 Rename、Download 与 Delete。空状态说明快照只保存在此浏览器。当前数据集没有 selection 时保存入口禁用并解释原因；导入始终可用。

恢复继续走现有 server-side JSON 验证与 browser apply 路径，保证本机快照和 Open JSON 完全一致。任何恢复或保存失败均在同一面板显示明确状态，且不改变当前视图。

## 测试与验收

- 单元契约覆盖库记录解析、指纹隔离、名称/数量/字节上限和 canonical JSON 不被改写。
- 浏览器测试覆盖保存、页面重载后列出、恢复、重命名、删除及下载。
- 浏览器测试覆盖不同数据集时本机快照不泄露到列表，且无 selection 时不能保存。
- 现有 JSON 导入导出回归测试继续通过。
