# Builder Cancel 按钮样式统一设计

## 目标

数据集导入区中，“正在读取”和“排队等待”两种状态的 Cancel 操作使用相同的视觉语言，避免相同行为看起来像两种不同操作。

## 决定

- 两个 Cancel 按钮统一使用现有的 `btn-remove-soft` 浅红危险样式。
- 两个按钮保持一致的内边距、圆角、字号和最小高度。
- 保留现有按钮位置：当前导入按钮仍位于服务端导入行，排队按钮仍位于客户端队列行。
- 保留现有事件、可访问名称、禁用状态和取消逻辑；本次不改变行为。

## 实现边界

- 为服务端当前导入行的 Cancel 按钮补上与客户端排队按钮相同的样式 class。
- 若两种行的局部 CSS 对按钮尺寸有分叉，收敛为一个共享规则。
- 不修改 Remove、Retry、弹窗 Cancel 或其他页面按钮。

## 验收

- 同屏出现当前导入和排队导入时，两个 Cancel 按钮的背景、文字颜色、边框、圆角和高度一致。
- 两个按钮仍分别取消正确的导入任务。
- 长文件名和窄屏下按钮仍留在数据集卡片内。
