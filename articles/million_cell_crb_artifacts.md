# Reproduce the one-million-cell CRB artifacts

## Purpose

This vignette records exactly which public data are used for the
one-million-cell CRB benchmark, how the data are transformed, where
every artifact is stored, and how to reproduce both physical CRB codecs.
It measures storage and I/O engineering behavior; the deterministic
one-million-cell subset is not a new biological analysis cohort.

## Source data

The source is the 10x Genomics **1M Neurons** data set: E18 mouse brain
nuclei processed by Cell Ranger 1.3.0. The public HDF5 matrix contains
1,306,127 cell barcodes and 27,998 features.

``` text
https://cf.10xgenomics.com/samples/cell-exp/1.3.0/1M_neurons/
  1M_neurons_filtered_gene_bc_matrices_h5.h5
```

The preparation script downloads this file without modifying it. The
generated data do **not** live under the repository root. The repository
contains the preparation and benchmark code, while the large source and
derived artifacts live in an external user-cache directory.

| Location | Resolved path | Relationship |
|----|----|----|
| Repository root | /home/runner/work/CerebroNexus/CerebroNexus | Git-tracked source, tests, and vignette only |
| Large-example cache root | /home/runner/.cache/R/CerebroNexus/large-examples | External to the repository; replaces `<cache-root>` below |
| One-million-cell data root | /home/runner/.cache/R/CerebroNexus/large-examples/1m | `<cache-root>/1m/` |

By default, `<cache-root>` is
`file.path(tools::R_user_dir("CerebroNexus", "cache"), "large-examples")`.
On the recorded macOS host this resolves to
`/Users/nuioi/Library/Caches/org.R-project.R/R/CerebroNexus/large-examples/`.
Set `CEREBRO_LARGE_CACHE` to replace that complete cache-root path; for
example, `CEREBRO_LARGE_CACHE=/Volumes/FastSSD/cerebro-large-examples`
stores the dataset at `/Volumes/FastSSD/cerebro-large-examples/1m/`. A
fresh run needs approximately 16 GiB of free space.

## Processing steps

The transformation is deterministic:

1.  Open the public 10x HDF5 matrix with BPCells.
2.  Select exactly 1,000,000 barcodes at evenly spaced source indexes.
3.  Replace Ensembl row identifiers with unique `gene_names` symbols.
4.  Convert non-negative integer counts to BPCells `uint32_t` storage.
5.  Run
    [`NormalizeData()`](https://satijalab.org/seurat/reference/NormalizeData.html)
    and
    [`FindVariableFeatures()`](https://satijalab.org/seurat/reference/FindVariableFeatures.html).
6.  Draw a 50,000-cell leverage-score sketch with seed 123.
7.  Run 30-component PCA, neighbours, clustering at resolution 1, and
    UMAP with seed 123 on the sketch.
8.  Project the PCA, cluster labels, and UMAP back to all 1,000,000
    cells.
9.  Save a Seurat RDS plus its BPCells expression sidecar.
10. Export counts, `sample`, `seurat_clusters`, and the full UMAP to a
    BPCells-backed CRB.
11. Re-encode only the CRB control payload as thin RDS and thin qs2.
    Both files reuse the same unchanged Cerebro BPCells sidecar.

The thin CRB uses the sidecar’s ordered `col_names` as its canonical
cell index. It omits the live expression handle,
`meta_data$cell_barcode`, and projection barcode row names, records the
`col_names` checksum, and restores those fields in
[`readCerebro()`](https://mihem.github.io/CerebroNexus/reference/readCerebro.md).

`<cache-root>`, not to `<repository-root>`:

``` text
<cache-root>/
└── 1m/
    ├── source/
    │   └── 1M_neurons_filtered_gene_bc_matrices_h5.h5
    ├── seurat/
    │   ├── mouse_brain_1m.rds
    │   └── mouse_brain_1m.bpcells/
    └── cerebro/
```

`.crb` identifies the logical Cerebro data format, not the physical
codec. Use
[`readCerebro()`](https://mihem.github.io/CerebroNexus/reference/readCerebro.md)
for every new or old CRB. Direct
[`readRDS()`](https://rdrr.io/r/base/readRDS.html) remains valid only
for files explicitly written with `codec = "rds"` and legacy RDS CRBs.

## Comparison against PR \#165

The benchmark baseline is the legacy RDS CRB from PR \#165 (`69893a2b`,
CerebroNexus 4.4.3). The optimization branch is based directly on that
merge commit and develops the CRB changes as CerebroNexus 4.5.0.

| Storage | Apple SSD `AP1024R`, 1 TB, APFS, Apple Fabric |

| Architecture | `arm64` |

| Seurat / SeuratObject | 5.5.1 / 5.4.0 |
| Benchmark baseline | PR \#165 (`69893a2b`), CerebroNexus 4.4.3 |
| Optimization candidate | `perf/pr0-million-cell-crb-qs2`, based on PR \#165 (`69893a2b`), CerebroNexus 4.5.0 development version |

Measurements are warm-cache medians from five alternating rounds on the
same unchanged BPCells sidecar. The benchmark loads the source checkout
with
[`pkgload::load_all()`](https://pkgload.r-lib.org/reference/load_all.html);
the separately installed CerebroNexus 5.0.0 package is not used.

`Write` includes thin-payload compaction and serialization. `Decode`
measures only physical deserialization. `Hydrated read` measures
[`readCerebro()`](https://mihem.github.io/CerebroNexus/reference/readCerebro.md),
including reopening the BPCells sidecar, validating its canonical cell
index checksum, and restoring omitted metadata and projection row names.

| Candidate | Codec | CRB size | Write median | Decode median | Hydrated read median | Size reduction vs PR \#165 | Write speedup | Decode speedup | Hydrated read speedup |
|----|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| PR \#165 legacy CRB (`69893a2b`, v4.4.3) | RDS | 26.83 MiB | 8001 ms | 1296 ms | 1479 ms | — | — | — | — |
| Thin CRB without qs2 (v4.5.0-dev) | RDS | 13.92 MiB | 2947 ms | 93 ms | 356 ms | 48.12% | 2.71x | 13.94x | 4.15x |
| Thin CRB with qs2 (v4.5.0-dev) | qs2 | 13.21 MiB | 231 ms | 41 ms | 297 ms | 50.75% | 34.64x | 31.61x | 4.98x |

Without qs2, thin CRB reduces the control file by 48.12%, accelerates
writing by 2.71x, physical decoding by 13.94x, and hydrated
[`readCerebro()`](https://mihem.github.io/CerebroNexus/reference/readCerebro.md)
by 4.15x relative to PR \#165. With qs2, the reductions are 50.75%,
34.64x, 31.61x, and 4.98x respectively. The incremental file-size
benefit of qs2 over thin RDS is only 5.07%; most of the size reduction
therefore comes from removing redundant CRB fields rather than changing
codec.

The checksum failure covered by the automated test is deliberately
injected to prove that a CRB cannot silently attach the wrong BPCells
sidecar. The genuine one-million-cell RDS and qs2 files used here both
pass checksum validation.

The following command reruns all five alternating benchmark rounds and
regenerates the source CSV used to record these measurements:

``` bash
BASELINE=$(Rscript -e 'cat(file.path(tools::R_user_dir("CerebroNexus", "cache"), "large-examples", "1m", "cerebro", "cerebro_mouse_brain_1m.crb"))')
Rscript tests/bench/benchmark_million_cell_crb.R "$BASELINE" 5 tests/bench/results/million_cell_crb_pr165.csv
```

## Run the complete preparation

The expensive chunks are disabled during ordinary package builds. Run
the complete workflow from the repository root with:

``` bash
CEREBRO_RUN_1M_VIGNETTE=true \
Rscript -e 'rmarkdown::render("vignettes/million_cell_crb_artifacts.Rmd")'
```

The following code performs the actual download, analysis, export, and
codec conversion when `CEREBRO_RUN_1M_VIGNETTE=true`.

``` r
source(file.path(repo_root, "tests", "bench", "prepare_viewer_1m_data.R"))
pkgload::load_all(repo_root, quiet = TRUE)

source_crb <- prepareViewer1mBenchmarkData(cache_dir = cache_root)
object <- readCerebro(source_crb)
stopifnot(length(object$getCellNames()) == 1000000L)

saveCerebro(object, paths$thin_rds, codec = "rds")
saveCerebro(object, paths$thin_qs2, codec = "qs2")
```

## Verify the outputs and regenerate the table

This final chunk reads both physical codecs through the same public API,
checks their exact cell and UMAP ordering, and regenerates the artifact
table from the files on disk.

``` r
expected_cells <- object$getCellNames()
expected_umap_cells <- rownames(object$getProjection("umap"))

for (path in c(paths$thin_rds, paths$thin_qs2)) {
  restored <- readCerebro(path)
  stopifnot(
    identical(restored$getCellNames(), expected_cells),
    identical(rownames(restored$getProjection("umap")), expected_umap_cells),
    identical(restored$meta_data$cell_barcode, expected_cells)
  )
  rm(restored)
  gc()
}

knitr::kable(artifact_table(), row.names = FALSE)
```

The BPCells directory is intentionally not copied for each codec. The
RDS and qs2 `.crb` files contain alternative serializations of the same
Cerebro control data and both point to
`cerebro_mouse_brain_1m.bpcells/`.
