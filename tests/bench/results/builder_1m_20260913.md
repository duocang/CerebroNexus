# Builder one-million-cell performance

The benchmark uses the cached official 10x E18 mouse-brain fixture with 1,000,000 cells, 27,998 genes, and a BPCells expression sidecar. Round 1 compares fresh native Builder imports in separate R processes. Round 2 uses five alternating warm rounds on the same legacy CRB and sidecar.

## Round 1: Builder import

| Candidate | Import wall time | Snapshot phase | Worker system CPU | Peak RSS |
| --- | ---: | ---: | ---: | ---: |
| `49a74b13` baseline | 29.094 s | 11.443 s | 2.805 s | 1,294,630,912 bytes |
| `6f2ab3f1` Builder optimization | 25.614 s | 8.173 s | 0.914 s | 1,313,914,880 bytes |

Import latency fell by 12.0%, the snapshot phase fell by 28.6%, and worker system CPU fell by 67.4%. Peak RSS changed by +1.5%, which is treated as no memory improvement. The logical snapshot payload stayed constant; the macOS path now uses copy-on-write clones for the 3.4 GiB BPCells backing directory and retains the ordinary-copy fallback on other platforms.

## Round 2: Thin CRB/qs2

| Candidate | Control payload | Write median | Decode median | Hydrated read median |
| --- | ---: | ---: | ---: | ---: |
| Legacy RDS | 26.829 MiB | 7,952 ms | 1,369 ms | 1,557 ms |
| Thin RDS | 13.920 MiB | 2,955 ms | 94 ms | 361 ms |
| Thin qs2 | 13.268 MiB | 235 ms | 41 ms | 310 ms |

Thin qs2 reduced the control payload by 50.5%, accelerated writes by 33.8 times, accelerated payload decode by 33.4 times, and accelerated complete BPCells hydration by 5.0 times. The one-million-cell RDS/qs2 conversion contract and Builder staged-CRB verifier both passed with exact cell-order checks.
